# Lyzr Usage Map

| Lyzr capability | CarbonGuard use |
|---|---|
| Agent Studio | Configure five specialized agents, roles, instructions, schemas and tools |
| Agent API | Inference/deployment boundary for agents |
| SDK | Programmatic application integration boundary |
| SuperFlow | Webhook-triggered end-to-end orchestration |
| Knowledge Base / Qdrant | Contextual retrieval/evidence layer |
| Safety / Evaluations | Governance and adversarial evaluation layer where enabled |
| Monitoring | Runtime visibility where enabled |
| Guardrails | Safety controls where enabled |
| AIMS | Governance/evaluation/monitoring framework for governed agent operation |

The repository distinguishes architectural support from features actually enabled in a deployment. Final claims should match the connected Lyzr environment and judge-visible configuration.
