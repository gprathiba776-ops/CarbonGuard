# Greenwashing Governance

CarbonGuard treats unsupported environmental claims as a governance failure, not as a writing problem.

For reduction claims, the system requires verified baseline/current evidence. It does not infer a reduction from narrative language.

Example adversarial test:

- baseline = 100 tCO2e
- current = 82.2 tCO2e
- claimed reduction = 40%
- supported reduction = 17.8%

The 40% claim is therefore not accepted.

The goal is simple: **if evidence does not support the claim, the disclosure pipeline must not approve it.**
