# Audit Lineage

CarbonGuard's canonical evidence chain is:

**Source Record → Activity → Scope → Factor → Formula → Result → Governance → Disclosure**

A final disclosure is approved only when the required chain is intact.

Minimum numerical evidence:
- activity
- quantity
- unit
- scope
- factor value
- factor unit
- factor ID
- factor source
- factor year
- deterministic formula
- emissions result

A missing material item produces review rather than invention.
