# Emission Factor Provenance

Numerical factors are sourced from the UK Government's 2026 greenhouse-gas reporting conversion factors dataset.

CarbonGuard records factor provenance including:

- factor ID
- scope
- category path
- activity
- unit
- factor value
- factor year
- source statement

The deterministic lookup service is the numerical authority. Semantic retrieval can assist contextual discovery/provenance but cannot override the deterministic match.
